
🗑️ Smart Dustbin – Embedded System Project
Project Description
The Smart Dustbin is an automatic dustbin that makes waste disposal easier, cleaner, and more hygienic. It uses an Arduino UNO, ultrasonic sensors, and a servo motor to control the dustbin automatically.
When a person brings their hand near the dustbin, the ultrasonic sensor detects it and the servo motor opens the lid automatically. After a few seconds, the lid closes automatically.
Another ultrasonic sensor checks how much waste is inside the dustbin. The Arduino calculates the approximate fill percentage. When the dustbin becomes almost full or full, a red LED and buzzer give an alert. 
# Main Features
* Automatic touchless lid
 *( Hand/object detection
 * Waste-level monitoring
 * Fill percentage calculation
 * LED status indication
 * Full-bin buzzer alert
 * Automatic lid closing
 * Sensor error detection
 * Serial Monitor monitoring
 * Wokwi virtual simulation
 * Components Used
 # Arduino UNO, 2× HC-SR04 Ultrasonic Sensors, Servo Motor, Green LED, Red LED, Buzzer, Breadboard, and Jumper Wires.
Applications
 # This project can be useful in homes, offices, hospitals, schools, colleges, malls, airports, railway stations, and smart-city waste-management systems.
Future Scope
 # The system can be upgraded using ESP32, Wi-Fi, IoT, cloud monitoring, and mobile notifications for remote monitoring of multiple dustbins.
 # In simple words: This project automatically opens the dustbin, monitors how full it is, and alerts the user when it needs to be emptied.
